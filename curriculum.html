I pulled the full table of contents of twelve master.dev courses and assigned every section to a module, so recording prep is a checklist rather than a guess. Roughly 57 hours of English reference behind a 55–65 hour Arabic program.

Three things the mapping surfaced. One: the TanStack course is Start-centric — server functions, middleware, hydration — so only about forty minutes of it applies if M8 teaches Router standalone; we decide whether to add a Start bonus. Two: we cut React Performance v2 and Web Performance Fundamentals v2 from the plan — that is ten source hours gone, and it moves React's render model into M5 and the whole measurement toolchain into M10 as original material. Three: the Advanced Web Development Quiz maps almost one-to-one onto the mid/senior "why" round, so it gets used twice — as the module 1 diagnostic and as the module 13 question bank.
